# unraid-icons

Icons for the Unraid Docker tab, referenced from compose files through the
`net.unraid.docker.icon` label and served by jsDelivr:

```
https://cdn.jsdelivr.net/gh/DerpDerpFailer/unraid-icons@main/<name>-256.png
```

256 px PNG, cropped, real transparency. To change an icon, add a file with a new name:
jsDelivr caches `@main` for up to 7 days and Unraid caches icons locally.
